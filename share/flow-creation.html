MICO · HYPERFRAMES CREATION PIPELINE
FIG. 01 · CREATION

创作主流程 · 从一句话需求到成片

路由 → 简报 → 素材 → 编排 → 双重门禁 → 渲染发布 —— 任何一步不达标都打回重做，门禁不过不渲染
STAGE 01 · INTAKE

💬 需求一句话

· 输入：产品页 URL / PR / 文案

· 明确交付物形态与时长

· 本例：SkyNomad 30s ｜ POCO 10s

STAGE 02 · ROUTE

🧭 意图路由

· /hyperframes 统一入口

· 匹配 10 条工作流之一

· 本例 → /product-launch-video

STAGE 03 · BRIEF

📋 需求简报

· 意图访谈产出 BRIEF.md

· 唯一需求事实源

· 后续只读简报，不重开路由

STAGE 04 · MEDIA

🖼️ 素材采集

· 网站捕获 + resolve 取材

· BGM / 图标 / logo / TTS

· 可复用素材优先

STAGE 05 · AUTHOR

✍️ 合成编排

· index.html 主时间轴

· 场景子合成 composition-src

· GSAP 注册 __timelines

STAGE 06 · GATE 1

✅ 校验门禁

· npm run check 全量

· lint / 运行时 / 布局 / 对比度

· ❌ 有错误 → 打回编排

STAGE 07 · GATE 2

👁️ 审片门禁

· preview --background 常驻

· 人工看片逐段过

· 🪄 观感反馈 → 画面/声音回修

STAGE 08 · RENDER

🎞️ 无头渲染

· npm run render

· 逐帧 seek + 截图

· MP4 + 混音 WAV

STAGE 09 · VERIFY

🔍 逐帧验收

· 尾帧黑场 / 音频指标

· ASR 全文回听

· 对照简报逐项打勾

STAGE 10 · DELIVER

📦 交付

· publish 拿分享链接

· 或直接交付 MP4

· 项目入仓 · 版本可复现

❌ 有错误 · 打回
🪄 观感反馈 · 画面/声音回修
主链 · 自动执行 门禁 / 打回循环 交付出口 | 门禁不过 = 不渲染：check 0 错误 + 人工审片通过才进渲染 HYPERFRAMES@0.8.31 / 0.8.33
